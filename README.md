# Nutrio — Система персонализированного планирования питания 

**Nutrio** — это веб-приложение, предназначенное для персонализированного подбора рациона питания на основе физиологических параметров пользователя, его целей (похудение, поддержание, набор массы) и пищевых ограничений (аллергии, диеты).

Главная особенность системы — формализация задачи подбора меню как **оптимизационной задачи с ограничениями** по суточной калорийности и балансу белков, жиров и углеводов (БЖУ).

---

## 🚀 Функциональность

- 🎯 **Персонализированный расчёт:** Определение суточной нормы ккал и БЖУ.
- ⚙️ **Умный алгоритм составления меню:** Оптимизация выбора блюд с учётом установленных лимитов.
- 🚫 **Учёт жестких ограничений:** Исключение аллергенов (орехи, молоко, яйца, рыба) и поддержка специальных типов питания (вегетарианство, веганство, безглютеновая диета).
- 🛒 **Автоматический список покупок:** Формирование перечня необходимых продуктов на основе выбранного рациона.
- 💾 **Сохранение данных:** Сохранение выбранных карточек в «Избранное» и автозаполнение полей формы (через `localStorage`).

## 💻 Локальный запуск

Для запуска проекта не требуются дополнительные сборщики или серверные зависимости:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/nutrio-app.git
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd nutrio-app
   ```
